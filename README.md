# Sincewhen

Recurring tasks that come due based on when you last did them — "change the air filter, every 2
months" — organized in folders: locations or categories, rooms, tasks and sub-tasks. Data stays
on the device.

Live at https://sincewhen.webwizarddev.com (the only address to use; `SITE_URL` in
`lib/site.ts`). About page: https://sincewhen.webwizarddev.com/about

```bash
pnpm install
pnpm dev
```
